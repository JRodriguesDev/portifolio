# José Rodrigues Portfolio

## Sobre

Portfólio desenvolvido para apresentar projetos,
habilidades técnicas, certificações e trajetória
na área de tecnologia.

## Tecnologias

- Next.js
- TypeScript
- Tailwind CSS
- Motion
- shadcn/ui

## Funcionalidades

- Apresentação de projetos
- Listagem de habilidades
- Certificados
- Download de currículo
- Layout responsivo
